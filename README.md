# مرکز فرمان UGOS

نمونهٔ قابل اجرای داشبورد فارسی برای تبدیل گزارش‌های ارسالی به Gmail به «تصمیم مستند، گردش‌کار n8n و تسک قابل پیگیری».

## اجرای محلی

به Node.js 20 یا جدیدتر نیاز است.

```powershell
node server.js
```

سپس `http://localhost:8787` را باز کنید. هیچ وابستگی npm لازم نیست.

```powershell
npm test
```

## این نمونه چه چیزهایی را پیاده می‌کند؟

- داشبورد RTL فارسی با سه نقش عملیاتی: مدیرعامل، مدیر بخش و عضو تیم
- تبدیل گزارش نمونه به پروندهٔ تصمیم بر مبنای UGOS: «واقعیت»، «تحلیل» و «فرض» جدا از هم
- گیت کیفیت تصمیم در backend: تا تعریف مسئله، علت ریشه‌ای، اثرات چندبعدی و تأییدها کامل نشوند، تسک صادر نمی‌شود
- کارتابل تأییدها و ثبت نظر مدیرعامل/مدیر بخش
- کانبان تسک‌ها، مالک، موعد، وابستگی و معیار پذیرش
- مرکز عملیات برای مشاهدهٔ سلامت اتوماسیون، صف‌ها، نرخ خطا و رخدادها
- API محلیِ آزمایشی و وب‌هوک امن برای اتصال n8n

## مرز نمونه با محیط واقعی

این پروژه یک MVP تعاملی است؛ داده‌های نمایشی در حافظه نگه‌داری می‌شوند. در محصول واقعی، داده باید در PostgreSQL ذخیره شود، فایل‌ها در S3-compatible Object Storage و صف‌ها در Redis/Queue قرار گیرند. `docs/production-architecture.md` نقشهٔ اجرای تولیدی و کنترل‌های لازم را مشخص می‌کند.

## فایل‌های کلیدی

- `server.js`: سرور محلی و APIهای نمونه
- `lib/decision.js`: گیت تصمیم، تأیید، ارجاع و وضعیت تسک
- `lib/static-path.js`: محدودسازی مسیر فایل‌های استاتیک
- `index.html`, `app.css`, `app.js`: رابط کاربری فارسی
- `n8n/UGOS-Report-Intake.workflow.json`: الگوی واردشدنی در n8n برای ساخت جریان Intake؛ پیش از اجرای واقعی Credentialها، مدل و URL باید پیکربندی شوند.
- `docs/production-architecture.md`: معماری، امنیت، CI/CD و برنامهٔ استقرار
- `docs/api-contract.md`: قرارداد API و وضعیت‌های جریان کار
- `test/decision.test.js`: آزمون واحد گیت تصمیم و path traversal

## متغیرهای محیطی نمونه

در محیط توسعه، وب‌هوک بدون secret هم کار می‌کند. اگر `NODE_ENV=production` باشد secret اجباری است.

```powershell
$env:N8N_WEBHOOK_SECRET = 'یک-کلید-تصادفی-حداقل-32-کاراکتر'
node server.js
```

در n8n همان مقدار را در هدر `x-ugos-webhook-secret` ارسال کنید.
