# قرارداد API نسخه ۰٫۱

پایه: `http://localhost:8787`  
رمزگذاری: UTF-8 JSON  
خطاها: `{ "error": "پیام فارسی" }`

این قرارداد وضعیت فعلی MVP را توصیف می‌کند. فیلدهای احراز هویت واقعی، صفحه‌بندی و نسخه‌بندی `/api/v1` در نسخهٔ تولید اضافه می‌شوند.

## وضعیت پرونده (Report.stage)

| وضعیت | معنی |
|---|---|
| نیازمند بررسی | ورودی جدید؛ هنوز از گیت شواهد عبور نکرده |
| نیازمند اطلاعات | ارجاع شده برای تکمیل داده یا اعتبارسنجی فرض |
| در انتظار تأیید | شواهد کافی؛ تأیید مدیر بخش و/یا مدیرعامل باقی است |
| گردش‌کار فعال | هر دو تأیید ثبت شده و گیت تصمیم عبور کرده |

## وضعیت تسک

`برای شروع` → `در حال انجام` → `بازبینی` → `انجام‌شده`

## گیت تصمیم

تا وقتی همهٔ شرط‌های زیر برقرار نباشند، تأیید دوم گردش‌کار صادر نمی‌کند (HTTP `409`):

- مسئله تعریف شده
- حداقل یک واقعیت مستند
- علت ریشه‌ای مشخص (نه «نامشخص»)
- فرض‌ها به‌صورت آرایه ثبت شده‌اند (حتی خالی)
- اثر چندبعدی ثبت شده
- مالک تعیین شده
- تأیید `ceo` و `department` هر دو `تأیید شده`

## مسیرها

### `GET /api/dashboard`
شاخص‌های نمایشی و سلامت نمونه.

### `GET /api/reports`
`{ "data": Report[] }`

### `GET /api/tasks`
`{ "data": Task[] }`

### `POST /api/reports/:id/approve`
بدنه:

```json
{ "role": "ceo" }
```

`role` فقط `ceo` یا `department`.  
موفق: `{ "data": Report, "auditId": "uuid", "gate": { "checks": {}, "passed": true } }`

### `POST /api/reports/:id/return`
بدنه:

```json
{ "comment": "نیاز به استعلام جایگزین" }
```

پرونده به `نیازمند اطلاعات` برمی‌گردد.

### `POST /api/tasks/:id/status`
بدنه:

```json
{ "status": "در حال انجام" }
```

### `POST /api/webhooks/n8n/report`
هدر اجباری در production: `x-ugos-webhook-secret`  
بدنه حداقلی:

```json
{
  "project": "پروژه آفتاب",
  "subject": "تأخیر تأمین بتن",
  "facts": ["ظرفیت روزانه نصف شده است."],
  "sender": "n8n",
  "owner": "مدیر پروژه",
  "priority": "بحرانی",
  "confidence": 86,
  "analysis": "متن اختیاری",
  "assumptions": [],
  "rootCause": "متن اختیاری",
  "proposal": "متن اختیاری",
  "impacts": {}
}
```

پاسخ موفق: `201 { "data": Report }`

## کدهای وضعیت

| کد | معنی |
|---|---|
| 200 / 201 | موفق |
| 400 | JSON نامعتبر |
| 401 | وب‌هوک بدون secret معتبر |
| 404 | پرونده، تسک یا نقش نامعتبر |
| 409 | گیت تصمیم کامل نیست |
| 422 | فیلد الزامی وب‌هوک نیست |
